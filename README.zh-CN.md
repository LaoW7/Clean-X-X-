# 清简 X

[English](README.md) · **简体中文**

清简 X 是一个 Chrome 扩展。它将 X 的时间线居中，让主导航只保留「主页」和「探索」，并让你决定图片、GIF 和视频在时间线里占多少空间。

## 功能

- **时间线居中。** 桌面上的主栏保持居中，窄窗口会自动收窄。右侧的趋势和推荐等模块会收起，时间线里能识别的推广帖也会隐藏。
- **保留主页、探索和搜索。** 左侧导航只显示「主页」和「探索」。视口宽度达到 1,080 CSS 像素时，如果页面有右侧原生搜索框，扩展会保留它和搜索建议。窗口更窄时，可以到「探索」搜索。
- **大图链接预览变成文字链接。** 外部网页卡片会换成一行可点击的链接，保留原跳转地址。正文已有同一链接时，只保留正文里的那条。点进帖子详情可查看原卡片。
- **返回时恢复阅读位置。** 点进帖子再返回时，扩展会根据离开前屏幕上的帖子恢复位置，即使时间线的高度发生了变化。如果 X 已经没有加载到原来的帖子，扩展会尝试使用离开前的滚动距离。手动滚动会优先于自动恢复。
- **设置即时生效。** 设置保存在当前 Chrome 浏览器中，并应用到已经打开的 X 标签页。关闭面板里的两个模式开关即可恢复 X 的原版界面。

## 工作模式

扩展面板里的「工作模式」是独立开关。开启后，X 使用带深蓝页眉、浅色背景和低调时间戳的技术资讯布局，时间线以正文和链接为主，媒体在帖子详情里显示。工作模式可以单独开启，关闭后会恢复之前保存的精简模式和媒体设置。

## 时间线媒体

打开 Chrome 扩展菜单中的「清简 X」，在「时间线媒体」下选择一种显示方式。

| 选项 | 效果 |
| --- | --- |
| **仅详情页显示（默认）** | 隐藏时间线里的图片、GIF 和视频。点开帖子正文或点击时间戳即可查看完整媒体。 |
| **显示缩略图** | 在紧凑区域中按原比例显示最多四张小图。GIF 和视频有封面时显示静态封面。点击缩略图或「查看媒体」可打开帖子。 |
| **保持原尺寸** | 图片、GIF 和视频按 X 的默认方式显示。开启精简模式时，时间线里的外部网页预览仍会显示为文字链接。 |

## 从 GitHub 安装

1. 在 GitHub 仓库页面选择 **Code → Download ZIP**，然后解压文件。也可以克隆仓库。
2. 使用 Chrome 105 或更新版本，打开 `chrome://extensions/` 并开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选中包含 `manifest.json` 的文件夹。
4. 打开或刷新 [X](https://x.com/)。从扩展菜单打开「清简 X」，也可以将它固定到工具栏。

下载新版后，用新版文件替换本地扩展文件夹中的文件，到 `chrome://extensions/` 点击扩展卡片上的「重新加载」，再刷新 X。

## 权限与使用范围

- 清简 X 只在 `x.com` 和 `twitter.com` 上运行，通过 `storage` 权限在当前浏览器中保存精简模式和媒体偏好。
- 扩展调整的是页面显示。X 仍可能下载已经隐藏的媒体，无法识别的推广帖也可能继续显示。
- 扩展依赖 X 的页面结构。如果 X 改版，部分功能可能需要随之更新。

## 项目文件

| 文件 | 用途 |
| --- | --- |
| [manifest.json](manifest.json) | Manifest V3 配置、适用网站和权限 |
| [content.js](content.js) 和 [content.css](content.css) | 布局、内容过滤和链接预览 |
| [work-mode.css](work-mode.css) | 工作模式外观 |
| [media-thumbnails.js](media-thumbnails.js) | 按比例显示时间线里的图片和视频封面 |

直接加载源代码目录即可使用，无需构建。
